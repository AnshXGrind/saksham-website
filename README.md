# Ansh Portfolio — React + Vite

Minimal personal portfolio for Saksham Garg / AnshXGrind.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Works with Vercel, Netlify, GitHub Pages, or any static host.
